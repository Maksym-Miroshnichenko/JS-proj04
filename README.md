
# Солодка Майстерня
Солодка Майстерня — адаптивний вебсайт кондитерської, створений для зручного перегляду, вибору та замовлення десертів онлайн.

Основна мета проєкту — створити сучасний та зручний інтерфейс, який дозволяє користувачу:

переглядати каталог десертів;
фільтрувати десерти за категоріями;
переглядати детальну інформацію про десерт;
знайомитися з відгуками клієнтів;
переглядати інформацію про майстерню;
оформити замовлення через форму.

## Tech Stack

**Головні інструменти:** HTML5, CSS3, JavaScript

**Бібліотеки:** Swiper.js, Accordion.js, Axios, Raty.js, BasicLightbox, SimpleLightbox, SweetAlert2  

**Збирач:** Vite, SVG Sprite

**Backend:** [Desserts API docs](https://deserts-store.b.goit.study/api-docs/)
